# BBs Solutions

Webdesign, hosting en AI-ondersteuning voor het MKB. Beheer van deze GitHub-organisatie: **Ben**.

## Hoe deze organisatie werkt (voor mensen en AI-agents)

1. **Nieuwe sites ontstaan alleen vanuit de template.** Gebruik de template-repo (bbss-site-basis-familie) via "Use this template" en werk daarin. Oudere repo's zijn referentie, geen vertrekpunt.
2. **AGENTS.md leidt.** In elke actieve repo staat bovenaan een AGENTS.md met de vaste regels; lees die eerst. Kern ervan: pure HTML5 en vanilla CSS, semantische opbouw met data-section-attributen, één css/style.css met :root-tokens en BEM-classes, geen Tailwind/Bootstrap/React, geen inline styles.
3. **Vaste gang: audit, dan exacte wijziging.** Via PR's naar de actieve branch; squash-only, branches worden na merge automatisch geruimd.
4. **Productie** draait op Cloudflare Pages (of de eigen VPS); documentatie per repo staat in de README en eventueel de readme-branch.
